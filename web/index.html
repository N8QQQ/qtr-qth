Architectural Foundations

Designed for durability, resilience, and mathematical correctness under structural parity with production environments.

Stratum 0 Accuracy

Disciplines the host system clock by cross-referencing high-speed TTY pulse streams with local NTP offsets via statistical window analysis.

Self-Healing Sentinel

An active sentinel thread continuously audits connections, auto-negotiating baud rates and hot-swapping virtual TTY streams upon hardware interruptions.

Declarative Pipeline

Leverages functional paradigms and Vavr streams to construct an acyclic, immutable telemetry processor devoid of side effects.

Virtual Parity Labs

A multi-stage Docker orchestration layer provides hardware simulation environments (the Phantom Shack) to safely replicate signal dropouts.

Deploying the Sync Hub

To run qtr-qth natively or under virtual parity labs on Linux, use these rapid deployment sequences.

1. Verify Host System Setup
# Check dependencies and hardware connectivity
./gradlew probeHardware
./gradlew check
2. Build & Run with Docker Compose
# Boot the virtual simulator & hardware sentinel
docker compose -f docker/docker-compose.yml up --build -d
